# 🥚 すきたまご - 好きは、見つけるものじゃなくて、育つもの。

**まだ「好き」に出会えていない、あなたへ。**

「すきたまご」は、趣味や好きなことが見つからない人が、小さな体験を通して自分の「好き」に出会うきっかけをつくるiOSアプリです。

好きなことを診断するのではなく、**実際にやってみて、心が動いた瞬間を大切にする。**

そんな思いから生まれました。

## 🌱 開発背景

「何か新しいことを始めたいけど、何をすればいいかわからない」

「趣味がないから、自分には好きなことがないのかもしれない」

そんな悩みに対して、私たちは「好きがない」のではなく、「好きに出会うきっかけが少ない」のではないかと考えました。

そこで、日常の中で気軽にできる小さなクエストを通して、新しい一歩を踏み出せるアプリを開発しました。

## ✨ 主な機能

### 📸 1. 小さなクエストに挑戦

日常生活の中で、気軽に挑戦できるクエストを用意しています。

最初のクエストは **「身近な『きれい』を撮ろう」**。

空や花、街の景色など、自分が少しでも「いいな」と思った瞬間を写真に残します。

特別な知識や道具は必要ありません。

### 💭 2. 自分の気持ちを振り返る

クエストが終わったら、感じた気持ちを3つから選択します。

- 😊 楽しかった！
- 😌 ふつう
- 🌱 ちょっと違ったかも

どの回答にも正解・不正解はありません。

「楽しかった」だけでなく、「自分には合わなかった」と気づくことも大切な発見です。

撮影した写真や感想は、端末内に保存できます。

### 🐱 3. 「楽しい！」からキャラクターが誕生

写真クエストで「楽しかった！」を選ぶと、卵が孵化して **「カメラねこ」** が誕生します！

好きだと感じた瞬間が、かわいいキャラクターとして形になる仕組みです。

一方、「ふつう」「ちょっと違ったかも」を選んだ場合は孵化せず、同じ卵のまま次の体験に挑戦できます。

### 📖 4. 「すきのずかん」にコレクション

孵化したカメラねこは、図鑑へ自動的に登録されます。

図鑑では、誕生したキャラクターや孵化日時を振り返ることができます。

孵化後には新しい卵が登場し、次の「好き」を探す冒険が始まります。

### 📝 5. 体験の記録

過去に挑戦したクエストを「きろく」画面から確認できます。

- 撮影した写真
- 体験日時
- 振り返りで選んだ気持ち
- 任意の感想

小さな挑戦の積み重ねを、思い出として残せます。

### 🧭 6. クエストを探す

「さがす」画面では、以下のジャンルのクエストを閲覧できます。

| ジャンル | クエスト |
|---|---|
| 📸 写真 | 身近な「きれい」を撮ろう |
| 🚶 散歩 | いつもと違う道を歩こう |
| 🎵 音楽 | 知らない曲を1曲聴こう |
| 🎨 創作 | 今の気持ちを色で描こう |
| 📚 読書 | 気になる本を3ページ読もう |
| 🌿 観察 | 身近な小さな発見を探そう |

**現在実際に挑戦できるのは写真クエストのみです。**

そのほかのジャンルは一覧・詳細表示まで実装しており、今後の拡張を予定しています。

## 🔄 体験の流れ

1. 気になるクエストを選ぶ
2. 実際に小さな体験に挑戦する
3. 体験後の気持ちを振り返る
4. 「楽しかった！」ならキャラクターが孵化
5. 生まれたキャラクターを図鑑に登録
6. 新しい卵で次の「好き」を探す

「楽しくなかった」経験も記録として残り、次の一歩につながります。

## 🛠 使用技術

| 分野 | 技術 |
|---|---|
| 言語 | Swift |
| UI | SwiftUI |
| カメラ | UIKit / UIImagePickerController |
| 写真選択 | PhotosUI / PhotosPicker |
| データ永続化 | SwiftData |
| 設定・状態管理 | UserDefaults / @AppStorage |

### アーキテクチャ・特徴

- iOS 17以上を対象としたネイティブアプリ
- バックエンド・アカウント登録不要
- 端末内でのデータ永続保存
- オフラインでの基本機能利用
- VoiceOver・Dynamic Type・Reduce Motionに配慮した設計

## 📱 動作環境

- 対応OS：iOS 17以上
- 開発環境：Xcode
- 対応端末：iPhone

### 動作確認

iPhone SE（第3世代）/ iOS 18.2のSimulatorで、以下を確認しています。

- 写真選択から振り返りまでの操作
- 振り返り結果による自動孵化・非孵化の分岐
- カメラねこの図鑑登録
- 新しい卵への切り替え
- 体験記録の保存・閲覧

※実機カメラ撮影やiOS 17環境での動作は、別途確認が必要です。

## 🚀 今後の展望

現在は写真クエストを中心に実装していますが、将来的には散歩・音楽・創作・読書など、さまざまなジャンルへ拡張していきたいと考えています。

また、ジャンルごとに異なるキャラクターを用意し、ユーザーが見つけた「好き」を図鑑として集められる体験を目指しています。
